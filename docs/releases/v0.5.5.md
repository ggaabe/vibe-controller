# Vibe Controller 0.5.5

## A simpler, safer public setup

- Full USB capture is now developer-only while its input/vibration reliability
  is investigated. Public builds hide its controls, reject session startup,
  and no longer bundle its exclusive-USB helper or libusb dependency.
- On affected Xbox USB connections, Share shows a clear **Share unavailable on
  this USB connection** notice instead of prompting for Full USB permissions.
  Saved Share shortcuts and modifier layers are preserved; working Share
  transports and PlayStation Create are unchanged.
- **Native Universal Control remains the fresh-install default.** The signed
  virtual mouse/keyboard support installer is still bundled. Full USB capture
  is not required for cross-Mac handoff or normal controller vibration.

## Gabe's current saved configuration

- Fresh installs load **Gabe's Defaults**, exactly matching the current saved
  profile: cursor settings, global shortcuts, LB/RB combinations, Codex app
  overrides, and per-action vibration patterns.
- The importable snapshot remains at `Profiles/GAPE.json`. Existing profiles
  and explicit preferences are not overwritten or renamed during an upgrade.
- Default vibration remains enabled at 50% strength with the connection pulse
  enabled, matching Gabe's saved local preferences.

## Feedback and development work

- Modifier buttons now wait until their standalone action is actually taken
  before vibrating. A modifier combination uses the chosen action's feedback,
  without an extra bumper pulse when the modifier is released.
- Dev builds retain the opt-in Full USB experiment and the new one-time
  signed-helper approval flow, with lifecycle tests and clearer error reporting.
  **This release does not claim to fix Full USB vibration or session timeouts.**
- The filming script now demonstrates Vibe Controller improving its own real
  project, with the live map above Codex and a separate cross-Mac handoff shot.

If a previous Full USB session left vibration silent, quit the older app and
unplug/reconnect the controller before using the normal input path. Only run
one Vibe Controller instance at a time.

Download the signed, notarized Apple-silicon DMG below. The separate Virtual
Hardware Support package remains available for setup or repair.
