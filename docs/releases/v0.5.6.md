# Vibe Controller 0.5.6

## Smoother joystick movement in the background

- Protect active joystick movement from macOS App Nap and timer throttling,
  including when another app is in front or Vibe Controller is hidden.
- Keep the existing 120 Hz motion loop independent of UI work and fresh
  controller reports while a stick is held steady.
- Reset elapsed motion time when movement starts after idle to avoid a
  first-movement jump.
- Release the activity protection when motion settles, input is disabled,
  the controller disconnects, or Accessibility access is lost. Normal display
  and system sleep remain available.
- Add output timing diagnostics and regression coverage for sustained motion,
  both sticks, dead zones, and clean shutdown.

## Gabe's modifier shortcuts

- In **All Apps**, both **LB + Menu** and **RB + Menu** send **Tab**. Plain
  Menu still sends **Command-T**. PlayStation L1/R1 + Options work the same way.
- RB + Menu was already Tab in the previous install defaults; LB + Menu now
  matches Gabe's saved Dev profile as well.
- Existing saved profiles are preserved during updates. App-specific
  overrides still take precedence; Codex's modifier + Menu shortcut continues
  to jump to the next chat needing attention.

Download the signed, Apple-notarized Apple-silicon DMG below, or use
**Check for Updates** in the official app. Virtual Hardware Support remains
bundled and native Universal Control remains the install default.
