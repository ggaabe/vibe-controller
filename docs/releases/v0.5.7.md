# Vibe Controller 0.5.7

## Wired Xbox 360 support

- Adds a dedicated USB input decoder for genuine Microsoft wired Xbox 360 controllers (`045e:028e`) on macOS 15 Sequoia or newer, using Apple's built-in driver.
- Supports both sticks and stick clicks, independent analog triggers, D-pad, bumpers, A/B/X/Y, Start, Back, and Guide. Start maps to Menu, Back to View, and Guide to Home, preserving existing profiles and modifier layers.
- Works with USB-A directly or a data-capable USB-C adapter/hub. No legacy Xbox 360 kernel extension or experimental Full USB capture is needed.
- Fixes direct USB input taking over before a valid standard packet arrives, so an undecodable device no longer blocks the normal GameController fallback.
- Keeps one controller's input separate from other connected devices and restores fallback input when the active USB controller disconnects.
- Adds packet-decoding and input-routing regression tests, including existing Xbox Series and PlayStation paths.

The native Universal Control output path and saved profiles are unchanged. This patch adds no driver installation or new permission requirement beyond the app's existing setup.

## Compatibility note

Physical Xbox 360 and two-Mac handoff verification are still pending; automated packet tests are not hardware certification. Wireless 360 controllers connected by Play & Charge cable/receiver and third-party 360-style controllers are not validated by this addition. The Xbox 360 has no Share button. See the [support and hardware-test guide](https://github.com/ggaabe/vibe-controller/blob/v0.5.7/docs/XBOX-360.md).

Packaged downloads remain Apple-silicon only. The app's general macOS 14 minimum is unchanged; native wired Xbox 360 input requires macOS 15 or later.
